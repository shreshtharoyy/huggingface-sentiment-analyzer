# HuggingFace Sentiment Analyzer

A simple NLP application built using HuggingFace Transformers and PyTorch to perform sentiment analysis on user-provided text inputs.

The project uses a pretrained transformer model to classify text as:
- Positive
- Negative

## Features

- Interactive sentiment prediction
- Transformer-based NLP inference
- Real-time user input analysis
- Confidence score display
- Multiple sample review testing

## Technologies Used

- Python
- HuggingFace Transformers
- PyTorch

## Concepts Demonstrated

- Transformer Inference
- NLP Classification
- Pretrained Transformer Models
- HuggingFace Pipelines

## Example Output

```python
Enter text: I really enjoyed this movie!

Sentiment: POSITIVE
Confidence: 99.87%
```

## Installation

```bash
pip install transformers torch
```

## Run the Project

```bash
python app.py
```

## Project Purpose

This project was built to gain hands-on experience with:
- HuggingFace pipelines
- Transformer inference workflows
- NLP-based text classification
